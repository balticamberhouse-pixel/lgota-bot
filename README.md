# Льгота.Бот

Справочный Telegram-бот и небольшой веб-лендинг. Бот помогает пользователю сориентироваться в возможных категориях мер поддержки и перейти к официальным источникам для проверки условий.

> Важно: данные в `benefits_database.json` — стартовые справочные карточки, а не юридическая консультация. Условия, суммы и порядок оформления зависят от региона и меняются. Перед публикацией каждой карточки проверьте её по официальным источникам.

## Что внутри

- `benefits_bot.py` — Telegram-бот на `pyTelegramBotAPI`.
- `benefits_database.json` — карточки мер поддержки.
- `app.py` — Flask-лендинг.
- `requirements.txt` — Python-зависимости.
- `Procfile` — пример команд для платформ с web/worker-процессами.

## Запуск локально

1. Установите Python 3.10+.
2. Откройте терминал в папке проекта.
3. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

4. Активируйте его:

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Windows CMD:

```bat
.venv\Scripts\activate.bat
```

macOS/Linux:

```bash
source .venv/bin/activate
```

5. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

6. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
7. Задайте токен **только в переменной окружения**. Не помещайте его в код и не отправляйте в GitHub.

Windows PowerShell (только для текущего окна):

```powershell
$env:BOT_TOKEN="ваш_токен"
python benefits_bot.py
```

Windows CMD:

```bat
set BOT_TOKEN=ваш_токен
python benefits_bot.py
```

macOS/Linux:

```bash
export BOT_TOKEN="ваш_токен"
python benefits_bot.py
```

Если всё настроено верно, в терминале появится сообщение о запуске. В Telegram откройте бота и отправьте `/start`.

## Локальный запуск лендинга

В другом окне терминала (с активированным окружением):

```bash
python app.py
```

Откройте `http://127.0.0.1:5000`.

Перед публикацией сайта задайте имя бота:

Windows PowerShell:

```powershell
$env:BOT_USERNAME="your_bot_username"
python app.py
```

macOS/Linux:

```bash
export BOT_USERNAME="your_bot_username"
python app.py
```

## Безопасность и данные

- Не собирайте в боте паспортные данные, СНИЛС, ИНН, номера карт, фотографии документов или медицинские сведения без продуманной правовой и технической модели.
- Для первой версии не храните ответы пользователей — текущая версия держит их только в оперативной памяти до показа результата.
- Добавьте политику конфиденциальности и контакты владельца до привлечения аудитории.
- До монетизации консультаций обсудите правовые границы с профильным юристом.

## Деплой

Для платформы с отдельными процессами:

- `web`: `gunicorn app:app`
- `worker`: `python benefits_bot.py`

Укажите на платформе секрет `BOT_TOKEN` и, при необходимости, `BOT_USERNAME`. Не используйте один процесс для web и worker: оба должны работать отдельно.

## Следующий минимум продукта

1. Выберите один регион для пилота — например, Калининградскую область.
2. Проверьте и расширьте не более 10 карточек по официальным региональным и федеральным источникам.
3. Проведите тест с 10–20 пользователями.
4. Добавьте форму обратной связи без сбора лишних персональных данных.
